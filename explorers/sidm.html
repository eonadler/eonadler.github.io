Cross-section model

dσdΩ= σ0/m4π [1 + (v²/w²) sin²(θ/2)]²

Constant cross sections correspond to w → ∞ and sit in the shaded strip; within each strip row, markers are packed by host mass, so horizontal position there carries no other meaning. Hollow markers use an approximate (σ0, w) mapping of the paper's own parametrisation (a fit or a Rutherford-like form).

Transfer cross section

σT(v) = 2σ0(w/v)4 [ln(1 + v²/w²) − (v²/w²)/(1 + v²/w²)]

which tends to σ0 for v ≪ w. Bold segments span 0.5–2 Vmax of each zoom-in host, with Vmax = 37 km s−1 (Mhost/1010 M⊙)1/3. The coloured ruler above both plots uses the same relation: it marks the host whose Vmax equals w (or v), so a marker sitting left of its own colour is a model whose cross section is strongly velocity-suppressed in that host.

What is counted

Each marker groups runs that share (σ0, w), the colour attribute (host-mass bin, code or year) and the run type; marker area grows as √N. Re-analyses of existing runs, convergence re-runs and CDM twins are not counted. Faded markers come mostly from low-confidence table entries.
